# Прототип официального сайта СПК культуры и креативных индустрий

Интерактивный адаптивный прототип официального сайта Совета по профессиональным квалификациям в сфере культуры и креативных индустрий.

Реализованы: главная страница, навигация, динамические показатели, «Профстандарт дня», основные направления деятельности, каталог профессиональных стандартов, проекты с фильтрами, события и календарь, интерактивная структура Совета, документы, новости, глобальный поиск, демонстрационный личный кабинет и версия для слабовидящих.

Персоналии, контакты, документы, изображения и часть содержательных данных в прототипе являются демонстрационными и подлежат замене после утверждения официального контента.

Открытие опубликованной версии: `index.html`.
