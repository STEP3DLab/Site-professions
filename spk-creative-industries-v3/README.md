# СПК культуры и креативных индустрий — Creative Edition 1.2

Третья опубликованная итерация интерактивного концепта официального сайта Совета по профессиональным квалификациям в сфере культуры и креативных индустрий.

## Открыть

- GitHub Pages: https://step3dlab.github.io/Site-professions/spk-creative-industries-v3/
- Исходники: https://github.com/STEP3DLab/Site-professions/tree/main/spk-creative-industries-v3

## Три UX/UI-сессии

1. **Creative identity:** редакционная типографика, живая цветовая система, органические формы, фактура, нестандартная композиция и визуальный навигатор отраслей.
2. **Task-first UX:** быстрые пользовательские сценарии, отраслевой фильтр, путь «сигнал рынка → профстандарт → квалификация → НОК», улучшенная мобильная навигация и глобальный поиск.
3. **Motion, accessibility, performance:** управляемая анимация, `prefers-reduced-motion`, выраженный фокус, крупные интерактивные цели, focus trap в диалогах, отсутствие тяжёлых внешних библиотек.

## Что можно показывать

- главную страницу и показатели 570 / 100 / 2 583;
- каталог профессиональных стандартов и квалификаций;
- структуру Совета, проекты, события, документы и отчёты;
- поиск, фильтры, календарь, модальные страницы и мобильную версию;
- демонстрационный «Паспорт прототипа» с разграничением утверждённых и тестовых данных.

## Статус

Это демонстрационный функциональный концепт для согласования дизайна, структуры и пользовательских сценариев. Персоналии, официальные документы, контакты, реестры, фотографии и реквизиты, не предоставленные заказчиком, остаются демонстрационными и подлежат замене перед публичным запуском.

## Техническая схема

`index.html` загружает семь служебных фрагментов из той же папки, объединяет и распаковывает автономный HTML. Внешние шрифты, изображения, JavaScript-библиотеки и WebGL не используются.
