# СПК ККИ — итоговая демонстрационная версия

Канонический адрес итогового брендированного прототипа сайта Совета по профессиональным квалификациям в сфере культуры и креативных индустрий.

## Открыть

- GitHub Pages: https://step3dlab.github.io/Site-professions/spk-creative-industries-release/
- Исходники: https://github.com/STEP3DLab/Site-professions/tree/main/spk-creative-industries-release

## Состав версии

- полный функционал Final Concept 2.0;
- проектный фирменный знак СПК ККИ;
- единая SVG-система интерфейсных и отраслевых иконок;
- главная карта экосистемы креативных индустрий;
- инфографика квалификационного цикла;
- маршруты соискателя, работодателя, образовательной организации и эксперта;
- иллюстрации для профстандартов, проектов и событий;
- адаптивная мобильная версия;
- поддержка клавиатурной навигации, контрастного режима и reduced motion;
- метаданные, favicon, печатные стили и отказоустойчивая загрузка.

## Статус

Версия предназначена для демонстрации коллегам и согласования целевого дизайна. Логотип является проектной концепцией. Перед официальным запуском необходимо утвердить знак, заменить демонстрационные сведения официальными, подключить CMS, серверные формы, аналитику и провести итоговый WCAG/Lighthouse-аудит на рабочем домене.
