# СПК ККИ — Brand & Visual Edition 3.0

Брендированная демонстрационная версия прототипа сайта Совета по профессиональным квалификациям в сфере культуры и креативных индустрий.

## Открыть сайт

- GitHub Pages: https://step3dlab.github.io/Site-professions/spk-creative-industries-brand-v3/
- Исходники: https://github.com/STEP3DLab/Site-professions/tree/main/spk-creative-industries-brand-v3

## Визуальная система

В сборку интегрированы:

- проектный фирменный знак СПК ККИ и горизонтальная версия логотипа;
- SVG-система тематических и интерфейсных иконок;
- главная иллюстрация экосистемы креативных индустрий;
- инфографика «Как работает система квалификаций»;
- инфографика пользовательских маршрутов;
- иллюстрации для профстандартов, проектов и событий;
- фирменная палитра: глубокий синий, фиолетовый, бирюзовый, коралловый и тёплый жёлтый;
- адаптивные стили и поддержка `prefers-reduced-motion`.

## Техническое решение

Версия использует устойчивую одно-доменную оболочку над Final Concept 2.0. Оболочка загружает исходный функциональный прототип и добавляет фирменные SVG-материалы, иконки и инфографику без внешних библиотек и сторонних сервисов.

## Статус материалов

Фирменный знак является проектной концепцией и должен быть отдельно утверждён Советом до использования в качестве официального логотипа. Персоналии, документы, контакты и реестровые данные, не предоставленные заказчиком, сохраняют демонстрационный статус.
