# СПК культуры и креативных индустрий — Concept 0.9

Интерактивный демонстрационный прототип будущего официального сайта Совета по профессиональным квалификациям в сфере культуры и креативных индустрий.

## Открыть опубликованную версию

- GitHack: https://raw.githack.com/STEP3DLab/Site-professions/a2a17b170436a97daa302a820090b0c9fe88708b/spk-creative-industries-v2/index.html
- GitHub Pages: https://step3dlab.github.io/Site-professions/spk-creative-industries-v2/

## Что реализовано

- главная страница, показатели 570 / 100 / 2 583 и «Профстандарт дня»;
- разделы «О Совете», «Деятельность», «Проекты», «События»;
- каталог профессиональных стандартов и квалификаций;
- структура Совета, персоналии, документы и отчёты;
- календарь, поиск, фильтры, карточки и модальные окна;
- мобильная версия и базовые функции доступности.

## Статус

Это функциональный концепт для согласования внешнего вида и логики. Персоналии, контакты, документы, реестры, фотографии и реквизиты, не предоставленные заказчиком, являются демонстрационными и должны быть заменены официально утверждёнными материалами до запуска публичного ресурса.

## Техническая структура

`index.html` загружает четыре одноимённых служебных файла `payload-1.txt` — `payload-4.txt` из той же папки. Такое размещение исключает кросс-доменные запросы, которые вызывали ошибку `Failed to fetch` в предыдущем предпросмотре.
